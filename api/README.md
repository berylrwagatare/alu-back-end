# api

Python scripts that use the JSONPlaceholder REST API
(https://jsonplaceholder.typicode.com) to gather employee TODO data and
export it as CSV and JSON.

| File | Description |
| ---- | ----------- |
| 0-gather_data_from_an_API.py | Display an employee's TODO list progress |
| 1-export_to_CSV.py | Export an employee's tasks to USER_ID.csv |
| 2-export_to_JSON.py | Export an employee's tasks to USER_ID.json |
| 3-dictionary_of_list_of_dictionaries.py | Export all tasks to todo_all_employees.json |

## Usage

    ./0-gather_data_from_an_API.py 2
    ./1-export_to_CSV.py 2
    ./2-export_to_JSON.py 2
    ./3-dictionary_of_list_of_dictionaries.py
